Install

Three steps, no store.

  1. Download the APK on the Android device.
  2. Open the file and allow installs from this source when Android asks.
  3. Install, open the app once, then add the widget from your home screen.
The checksum

About the manifest.

A SHA-256 value is a fingerprint of the file. If it matches the published value, the download is the build that was signed.

  • Format One line per file, as printed by sha256sum
  • Manifest SHA256SUMS sits beside the APK
  • Check sha256sum -c SHA256SUMS
